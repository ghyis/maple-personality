Maple Personality — Google Sheets (raw + bar graph, no cookies)

WHAT YOU GET
------------
Tab "raw" (from row 2):
  Column A = class result (Ren, Kaiser, pally, …)
  Column B = Shared (No until they press SHARE, then Yes for that completion)

Tab "graph":
  Classes in fixed order with COUNTIF counts + column bar chart (updates automatically).

SETUP
-----
1. Create a new Google Sheet (can be empty).
2. Extensions → Apps Script → replace code with ResultsLogger.gs → Save.
3. Run setupSheets once (dropdown → setupSheets → Run → authorize).
   This creates "raw" and "graph" tabs + the chart.
4. Deploy → New deployment → Web app
   - Execute as: Me
   - Who has access: Anyone
5. Copy the URL ending in /exec.
6. In index.html set:
   window.MAPLE_RESULTS_SHEET_URL = 'https://script.google.com/macros/s/XXXX/exec';
7. git commit + push to GitHub Pages.
